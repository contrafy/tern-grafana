# Tern SDK capability matrix (M0)

Verified against Tern 0.7.0 (9ca00e4) on macOS 27.0.1 arm64 (Apple M5), 2026-10-09. Rendering rows ran in an
isolated sandbox (`scripts/dev-tern.sh`, sandbox `/tmp/tg-tern`) with a throwaway spike plugin
(`.sandbox/spike-render/`, id `tern-grafana`, never shipped) linked through `scripts/dev-tern.sh link`. Evidence
quotes are from `tern ctl --control /tmp/tg-tern/ctl.sock ...` replies (`tree`, `dump`, `pick`, `perf`, `a11y`),
`tern ls --json` against the sandbox daemon, the sandbox logs (`tern-daemon.log` = host half, `tern.log` = window
half; spike lines are prefixed `spike.`) or `tern ctl shot` PNGs. Timings inside the plugin are `os.clock` deltas.
Raster rows used a throwaway `grafana/grafana:12.1.0` on :13000 with `grafana/grafana-image-renderer` 5.0.0 (both
removed afterwards).

Status: **Verified** (observed in this build), **Workaround** (the direct capability is missing; the named
substitute was observed working), **Unsupported** (observed absent or not working), **Unverified** (not exercised,
with the reason).

isolation above existed) with a throwaway plugin `.sandbox/spike-int/plugin` (id `tern-grafana`, never shipped).

## Design consequences

Rendering:

1. **Class-based SVG coloring.** `var()` in SVG attributes and inline `style` never paint. Series get `tg-s<n>`
   classes and threshold tones get tone classes, colored in the plugin sheet from theme variables, so charts follow
   light and dark (and live theme switches) without re-rendering. Grafana fixed hex colors are the only literal
   attributes.
2. **256 KiB cap: byte budget before point budget.** An SVG over 262144 bytes shows a placeholder, also when it
   replaces a drawn one. The renderer computes points per series from a byte budget (about 12.7 bytes per point at
   one decimal, minus axes), LTTB-downsamples to it, and falls back down the ladder (B, then A) if a panel still
   cannot fit.
3. **maxDataPoints is a config default, not pane-driven.** `cx.cols`/`cx.rows` are a constant 80 x 24 for plugin
   blocks and `resize` never fires, so maxDataPoints and `$__interval` come from a configured default tied to a
   fixed design width (viewBox about 1000 px). The image scales down to the pane; layout uses `row`/`col` and
   fractions, not cell counts.
4. **Blob cache growth: reuse by content hash, overlay cursor, conservative refresh.** Blobs are never evicted within
   a session (200 swaps = 200 cache files, 12.8 MB). Blob ids are content hashes: panels hash their frame and call
   `cx:blob` only when the SVG changed; the keyboard cursor and per-bucket hover columns are `image` overlay children
   that move by `basis` (0.001 ms per key, no new blob); refresh intervals stay at the dashboard's own interval and
   skip unchanged frames.
5. **Hover is a bonus, the cursor is the inspection model.** SVG `<title>` is stripped; per-bucket `title` columns in
   the overlay are the tooltip path (display unverified). The legend read-out follows the keyboard cursor.
6. **PNG render latency 5 s: ladder B is asynchronous, placeholdered and cached.** Render PNGs off the key path,
   cache them per (panel, range, size, theme), show a native placeholder meanwhile, and gate the rung on
   `/api/frontend/settings` `rendererAvailable`.
7. **Stat, gauge and bargauge are native kinds, not SVG.** `meter` (bar/ring/blocks with two threshold steps),
   `rate`, `badge` and `table` + `meter_cell` cover them; `chart` spark/bars only for small sparklines, accepting the
   grow-in animation on every update. Canvases (window-authored) can show these kinds but not `image`.
8. **Autocomplete is `input` + `list`, browse is `picker`.** The block owns the text; suggestions update per key
   within a frame. The modal `picker` in the `layer` region is for metric browsing.
9. **Keep the linked plugin dir clean.** Any file change under it reloads the plugin and re-initializes open blocks;
   e2e writes screenshots and captures elsewhere, and blocks `save` the state they need to survive a reload.

Integration:

10. **Two transports, chosen per context.** `tern.fetch` is the default (concurrent, 16 MiB cap, clean status/
    error/timed_out). Any context with a custom CA, client certificate or `insecure` uses curl via
    `tern.process.run`, because fetch has no TLS options (`invalid peer certificate: UnknownIssuer`).
11. **curl never sees secrets in argv.** Auth (bearer, basic, extra headers such as `X-Scope-OrgID`) is written as a
    curl config on stdin (`--config -`); argv carries only flags, paths and the URL. Pass `--max-time` plus a
    slightly larger `timeout_ms`; map curl exit codes 7/28/60 to the same error kinds as fetch.
12. **Every effect call is pcalled.** `tern.fetch` raises on malformed URL/method/header; `tern.process.run` raises
    when the binary is missing; agents calls raise on unknown panes. The adapters convert raises into the same
    error values as network failures.
13. **Callbacks are serialized and unordered.** Fetches run concurrently but callbacks run only when the VM is idle
    and in completion order. Panels/queries carry a request generation and drop stale answers; parse work in
    callbacks counts against the 2 s host budget.
14. **Secrets stay in memory only.** Block args and `save()` land in `<daemon socket>.state`; kv is a 0644 JSON
    file; both are restored on restart. Neither may contain tokens, token_cmd output, or URLs with credentials.
    Token redaction uses plain-find replacement, never `gsub` with the secret as a pattern. token_cmd stdout is
    trimmed; stderr is never shown verbatim.
15. **Block `init` must be idempotent.** Restored blocks re-run `init` with their args and saved state (and a
    plugin reload re-runs it too, see 9); one-shot side effects (opening panes, POSTing annotations) must not live
    in `init`.
16. **Browser fallback is a window-side `cx:open` or a route `{url=...}` answer.** Both open a Tern browser pane
    beside the origin. Host-half `cx:open` goes through our own `route.link`, which claims Grafana URLs, so the host
    asks for the browser with a URL the route passes through as `{url=...}` (marker or private scheme), never a
    plain dashboard URL.
17. **`route.link` always answers.** pcall the handler; on error return `{url = link.url}` so the click still opens
    the browser; unknown Grafana paths return nil (built-in browser pane, no OS dialog for http/https).
18. **Browser session is shared and sticky.** The Tern browser keeps Grafana cookies across panes and restarts.
    Ladder A relies on the user's own login. The e2e sandbox has its own jar (`CFFIXED_USER_HOME`), and e2e asserts
    browser content with `tern browser snapshot` because `tern ctl shot` does not capture page pixels.
19. **Status segment = kv cache + window refresh.** The host poller writes per-context firing counts to kv; the
    window formatter reads kv (0.05-0.09 ms) and a window timer calls `tern.chrome.refresh()` only when the cached
    value changed. The segment's `command` opens the inbox. It is invisible while the user's status bar is off, so
    toasts/inbox remain the primary surface.
20. **Toasts come from the window half or a live block `cx`.** Host timers have no cx; C3 polling for toast purposes
    runs in the window half (timer `cx`) or uses a captured block cx.
21. **G1 deploy annotations pair `command_started` (cwd) with `command_finished` (status, took_ms) per pane.**
    Remote panes are Unverified; the hook must tolerate running on another host's plugin copy.
22. **Lens claims are narrow, views re-check.** Claim `promtool query instant *`, `promtool query range *`,
    `amtool * *`-style forms, `logcli query *`, `curl *api/v1/query*`, `curl *api/ds/query*`; quotes are stripped
    and wrappers/env/stderr redirects ignored before matching; pipelines and stdout redirects are never lensed. Our
    curl claim hides Tern's built-in `lens.net.http`, so the view must handle JSON/error bodies itself.
23. **No host-side visibility signal.** Timers keep firing for hidden blocks; polling intervals must be
    conservative, and a visibility hint (window `focus` events written to kv) is the only available throttle.
24. **Carly exports register safely without Carly.** Register in the window half unconditionally; agents APIs exist
    and fail with clear errors (`pane runs no agent`, blank prompt) that G4 must surface.
