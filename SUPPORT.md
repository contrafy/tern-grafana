# Getting help

- **How do I ...?** Check [README.md](README.md) first, then open a
  [question issue](https://github.com/contrafy/tern-grafana/issues/new?template=question.md).
- **Something is broken.** Open a
  [bug report](https://github.com/contrafy/tern-grafana/issues/new?template=bug_report.md)
  with your tern-grafana, Tern and server versions. Redact tokens, passwords,
  internal hostnames and URLs from any config or logs you paste.
- **Ideas.** Open a
  [feature request](https://github.com/contrafy/tern-grafana/issues/new?template=feature_request.md).
- **Security.** Never in a public issue: see [SECURITY.md](SECURITY.md).
- **Tern itself** (crashes, sign-in, the plugin API): see the
  [Tern docs](https://docs.stencil.so/tern/); problems with Tern are not
  tern-grafana bugs.
